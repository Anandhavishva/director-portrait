PRASNEV PRASSI — FILM DIRECTOR PORTFOLIO
=========================================

FILES
- index.html       Main portfolio page
- style.css        Responsive dark cinematic styling
- script.js        Mobile menu, scroll reveals, cursor glow, current year
- assets/director-portrait.jpg  Portrait cropped from the supplied reference image

HOW TO RUN
1. Extract the ZIP.
2. Keep index.html, style.css, script.js, and the assets folder together.
3. Open index.html in a browser.
4. For publishing, upload the complete folder to Netlify, GitHub Pages, or your hosting provider.

EDITING NOTES
- Update the name, biography, project descriptions, contact details, and video links in index.html.
- The YouTube links and contact details are taken from the supplied reference.
- The film poster-style artwork is made with CSS gradients/shapes so the page works without extra image downloads.
- Google Fonts require an internet connection; fallback fonts are included.

This is a front-end static website. The contact links open the visitor's email app or phone dialer; no backend form is included.
